# PDFMeasure

PDFMeasure lets you upload any PDF and instantly verify sizes and dimensions without printing. It auto-detects the page format (A4, A3, Letter etc.), overlays a measurement grid in cm, mm, inches or pixels, and includes a ruler tool to measure distances between any two points. Built for designers, print shops, and anyone who needs to check PDF dimensions before sending to print. Runs entirely in the browser — no uploads, no servers, completely private.

## Features

- **Auto-detect page format** — A4, A3, Letter, Legal, and more
- **Measurement grid overlay** — switch between cm, mm, inches, or pixels
- **Ruler tool** — measure the distance between any two points on the PDF
- **100% client-side** — your files never leave your browser

## Getting Started

Open `index.html` in your browser, or visit the hosted version to start measuring PDFs immediately.
